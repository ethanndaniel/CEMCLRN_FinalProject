**PROBLEM STATEMENT**

Proper hydration is an essential need especially to students who study and work for hours on end. This project aims to create a tracker system that helps students drink the recommended water amount for the day. This system revolves around a load cell under a water bottle, to be read by an ESP 32 (Tier 1), which detects water consumption and refills locally. The cloud (Tier 2) then learns the user’s drinking patterns and predicts when they’re likely to forget to drink, sending reminders to meet the recommended water consumption.
